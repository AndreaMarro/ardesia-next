# ardesia-product-slice

Read only the relevant rows of docs/product-map.md, original criteria D01–D68 and canonical task dependencies. Work beyond M3/M4 when their actual prerequisites permit; no invented acceptance. Preserve one Core/Host, source revision, licensing, DRAFT and privacy. A course slice includes explanation, prediction, manipulation or procedure, test, feedback, recovery and transfer. A donor needs a real consumer, version/rights and REUSE/ADAPT/REPLACE/DEFER decision. Scientific tests cover units, assumptions, limiting cases and counterexamples, separately from UX. Public publication and human scientific/editorial approval cannot be generated by an AI reviewer. Return one user-visible capability, evidence and a bounded next step.
