# ardesia-sequential-review

## Inputs
Receive immutable source, raw diff, acceptance criteria and raw evidence without the author's desired verdict. Read docs/recurring-work.md sections 5–6 and only relevant scoped AGENTS/lessons. Record the actual author/reviewer contexts and capabilities; instructional read-only limits are not ACLs.

## Procedure
Check canonical task/criteria, source scope, prerequisites, ownership, budget and evidence bindings. Trace the actual consumer and relevant auth/revocation, recovery, signatures and DRAFT/rights. Reproduce a discriminating countercase when useful; do not rerun an unchanged full suite. Review procedural changes against both a false acceptance and a valid progression. Keep source, procedure, deployment and historical milestone identities separate.

## Output and errors
Return reproducible findings with severity and exact source lines, or the bounded reviewed scope and limits. Identify artifacts actually read, metadata merely observed and evidence reused. Missing bytes, mismatched SHA or unavailable independent context remain pending; they never become PASS. A model context is not human scientific/editorial/device approval.

## Proof
Record commands, toolchain, fixture, source SHA/digest, actual independent context and result reference. Required Verify belongs to the final published source, including documents. No source/cursor/service writes, publishing, merge, deployment, scheduler changes or approval impersonation.
