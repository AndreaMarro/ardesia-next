# ardesia-sequential-review

Receive immutable source, raw diff, test outputs and acceptance criteria without the author's desired verdict. Read docs/recurring-work.md sections 5–6 and the relevant scoped AGENTS/lesson. Reproduce a discriminating countercase when useful; do not rerun an unchanged full suite. Check source/environment bindings, consumers, auth/revocation, recovery, signatures, budget and DRAFT/rights as applicable. Distinguish self-check, distinct model context and human approval. Record actual author/reviewer contexts, SHA, reference and limits. Missing independent context remains review pending. No code/cursor/service writes, approval impersonation, merge or deployment.
