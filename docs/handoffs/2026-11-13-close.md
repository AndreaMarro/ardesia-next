## Avvio e riproduzione

Per provare le demo da una copia del repository con Node24:

```sh
npm ci
npm run build
npm run preview
```

Aprire `http://127.0.0.1:4173/fisica/index.html`. La demo non richiede database. I file in `apps/web/dist/fisica/` si aprono anche offline; i collegamenti esterni richiedono rete. Il workspace autenticato richiede invece PostgreSQL e account predisposti secondo il [README server](../../packages/server/README.md).

`npm run verify` richiede il database sintetico loopback `_test` configurato in `M3_TEST_DATABASE_URL`. Il runner browser richiede `ARDESIA_E2E_MODE=local`, `M3_BROWSER_DATABASE_URL` sul database `_browser` e una build della stessa sorgente. Non usare dati reali. I comandi del prototipo sono nella sua cartella; non vengono eseguiti dall’app né inclusi nel conteggio dei 693 test applicativi.
